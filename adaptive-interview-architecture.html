Complete System Overview

Presentation Layer

User Login → Domain Selection → Interview UI (Text/Voice) → Dashboard & Analytics

Application Layer

Interview Engine → Adaptive Decision Engine (RL-Inspired) → Final Report Generator

AI / ML Processing

Whisper STT · TF-IDF · Cosine Similarity · STAR Evaluator · Communication · Scoring

Domain Question DB · User Performance Store · Session History

Execution Flow

Login → Load Questions → Session → Response (Text/Voice) → Dual Pipeline → NLP → STAR + Communication → Scoring → Adaptive Decision → Next Question (Loop) → Report → Dashboard

Adaptive Logic

High: Harder + Cross Q · Medium: Same Level · Low: Easier + Hints + Coaching

Final Report

Overall Score · STAR · Communication · Technical · Confidence · Strengths · Weak Areas · Suggestions
