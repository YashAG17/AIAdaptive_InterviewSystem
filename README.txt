HOW TO DOWNLOAD / SHARE
-----------------------

Option A — Copy this entire folder (easiest)
  1. This folder is on your Desktop:
     C:\Users\91941\Desktop\Adaptive-Interview-Presentation
  2. Right-click the folder → Send to → Compressed (zipped) folder
  3. Share the .zip via Google Drive, email, or USB

Option B — Save as PDF for college submission
  1. Double-click adaptive-interview-architecture.html (opens in browser)
  2. Press Ctrl+P → Save as PDF
  3. Each slide section prints as a separate page

Option C — PNG screenshots for PowerPoint
  1. Open adaptive-interview-architecture.html in Chrome/Edge
  2. Scroll to each diagram section
  3. Press Win + Shift + S → capture the slide area
  4. Paste into PowerPoint (Ctrl+V)

Option D — Open interactive canvas in Cursor
  1. In Cursor: File → Open File
  2. Select: adaptive-interview-coaching-architecture.canvas.tsx
  3. Canvas opens beside chat with 5 tabbed diagrams
  4. Screenshot each tab for slides
